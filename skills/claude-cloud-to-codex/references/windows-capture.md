# Windows 客户端截图与翻页

适用于仍能查看的项目记忆、只显示在界面里的表格或无法复制的卡片。若能“复制消息”或“下载”，先用对应原文或原件。截图可证明当时看见的内容；源文件字节、被折叠的段落和原链接仍需分别获取。

## 谁操作什么

1. 用户在已登录的 Claude 桌面中打开目标项目，选中第一条笔记或聊天，展开待保留的正文。Codex 有获准的桌面工具时，可以接着选笔记和翻页。需要登录或系统交互授权时由用户完成。一个窗口每次只交给一方操作，避免截图正好拍到正在切换的项目。
2. Codex 列出可见的 Claude 窗口，按用户选中的标题核对十进制窗口句柄，选一个用户控制的私有暂存目录。不将截图写入 skill 安装目录、公开仓库、共享同步盘。不同项目、笔记或讨论使用各自的暂存子目录。运行命令的工作目录是安装后的 skill 目录。

   ```powershell
   ./scripts/claude-capture.ps1 -Mode List
   # 以下句柄仅为示例，换成刚列出的值。保持在当前 PowerShell 中执行，以便传递整型数组。
   ./scripts/claude-capture.ps1 -Mode Capture -WindowHandle 123456 -OutDir "$env:TEMP\migration-private\note-A" -Region 20,80,700,500
   ```

3. 首张先验画面。裁剪参数为客户区内的 x、y、宽和高，单位为物理像素，省略时仅保存所选窗口客户区。用允许的本地图像查看工具确认文字清晰、顶部/底部没有截断、没有项目外信息。程序可发现整张单色图；局部黑屏、遮挡和加载占位仍要人工或视觉核对。窗口最小化、Claude 不提供可渲染画面或布局变化时停下，恢复可见页面，或请用户使用系统截图工具选取该区域。脚本不会改抓整个屏幕。
4. 连续采集时选一种配合方式。

   - 使用者翻页时加 `-Count 8`，每次到同一项目的下一页后在 PowerShell 回车。Codex 可以每翻一页调用一次单张截图；不必等待交互式终端。需要定时配合时加 `-IntervalSeconds 5`，由操作者在两张之间推进。
   - 页面提供命名的可访问性滚动容器时，可加 `-ScrollName '从当前窗口读到的准确名称' -Count 12`。脚本在同一窗口找到唯一可见且可滚动的同名容器，每次推进约七成视口，在底部提前结束。没有相应控件或进度不动时改用单张；不同笔记之间的导航由已授权的桌面工具或用户执行。动态加载时增大间隔，核对两页有内容重叠。滚动条暂时到底不能证明历史已经全部加载。
   - 各批次使用随机批次名，同一批页码递增，已有文件不会重写。达到张数上限只表示本轮停止，继续以最后一页原文做衔接。

5. Codex 可在本地用视觉或可用的 OCR 做初次转录，再与截图逐页核对标题、日期、代码字符、链接文字和换页重叠段。无法辨认就标出来。若截图里出现文件卡片，回到同一原消息，走 [桌面文件下载](windows-download.md)；以源端下载的文件建立哈希映射。原记忆已进入目标作用域、聊天与附件关联均验收后，按用户要求清理这次产生的截图。用户自己提供的原件由用户决定留存。

可先运行 `./scripts/claude-capture.ps1 -Mode SelfTest`。它只创建一个带两种颜色的测试窗口，检查裁剪尺寸和区域内的像素，结束时删除该测试 PNG。自测成功仅证明当前 Windows 的窗口采集路径可用；实机首张检查仍有必要。
